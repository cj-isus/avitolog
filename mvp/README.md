# АВИТОЛОГ — компонентная основа демо

Local-first расширение Chrome/Edge и веб-предпросмотр одной рабочей области. Основа: WXT, React/TypeScript, Base UI, Dexie, Zod, Recharts и Lucide. Точные версии — в `package-lock.json`. Требуется Node >=22.12; первая локальная сборка выполнялась на Node22.21.1.

На 8 ноября 2026 года интерфейс разделён на общие UI-примитивы, функциональные экраны, application controller, предметную логику, хранение и интеграции. Готовые библиотеки подключены через небольшие обёртки с едиными props и CSS tokens. Происхождение кода, применимые notices и правила следующих заимствований описаны в [REUSE.md](REUSE.md).

## Структура

```text
src/
  App.tsx                 компоновка разделов и диалогов
  components/ui/          Button, Field, Input, Dialog, Card, Badge и другие примитивы
  components/layout/      общая оболочка рабочей области
  features/               listings, comparison, market, negotiation, brief
  application/            useWorkspace, фабрика карточки, выбор и перенос данных
  domain/                 схемы, идентичность, отбор, аналоги, черновик
  data/                   Dexie и вымышленные примеры
  integrations/avito/     чтение отдельной карточки по явному действию
  lib/                    общие подписи и форматирование
  styles/                 tokens, base, primitives, layout, features
```

Правила оценки живут в `domain`, транзакции — в `data`. Экран получает данные и обработчики через props/controller; UI-примитивы не обращаются к IndexedDB или Avito. Recharts загружается отдельным lazy-компонентом при показе достаточного набора аналогов; те же числа доступны текстом.

## Запуск

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run prepare
npm run typecheck
npm test
npm run build
npm run build:preview
npm run preview
```

Предпросмотр: http://127.0.0.1:4178/. Веб-версия не получает доступ к вкладкам и аккаунту Avito. IndexedDB хранится на origin текущего интерфейса; extension и веб-предпросмотр не синхронизируются автоматически. Перенос — через JSON.

Для ручной проверки расширения: Chrome/Edge → Extensions → Developer mode → Load unpacked → каталог `.output/chrome-mv3`. Используйте отдельный тестовый профиль. Нажатие значка расширения открывает боковую панель; из неё доступна отдельная рабочая область. Повторный browser action может понадобиться для `activeTab` после смены вкладки/origin. Установка в пользовательский авторизованный профиль в этой работе не выполнялась.

## Работает сейчас

- Пять разделов: радар, сравнение, цены выбранных аналогов, черновик, требования.
- Пустое состояние и шесть явно вымышленных примеров.
- Ручное добавление/уточнение, локальное хранение, JSON import/export.
- Проверка колёс, заявленного диапазона роста и цены с заданным резервом. Неизвестное — отдельный исход.
- До четырёх карточек в сравнении. Диапазон/медиана цен выбранной группы; при нехватке данных расчёт не выдаётся.
- Два вопроса и редактируемое условное предложение; только копирование текста.
- Адаптер чтения отдельной открытой карточки по user gesture, проверенный на DOM fixtures. Live Avito и реальные browser grants требуют отдельной проверки.

Никаких ключей модели, фонового обхода Avito, чтения cookies, массовой отправки, покупки или изменения VPN. LLM-адаптер, неизменяемый журнал снимков, карта, анализ фото, мобильный осмотр и граф доказательств — следующие этапы. Десять изображений показывают целевой UX, а не фактический объём starter.

## Проверки и упаковка

`npm test` содержит **23 проверки**: отказы по неизвестному, ограничения, аналоги и дубли, строгую цену/DOM identity, лимит базы и rollback/concurrent writes через fake-indexeddb; отдельно — фабрику, выбор, JSON-перенос и конкуренцию начального чтения требований с сохранением/импортом в React controller. Эти проверки относятся к локальной логике и данным; они не заменяют браузерную приёмку нового UI.

Исторический [verification.json](verification.json) от 6 ноября фиксирует **17 тестов и 15 браузерных сценариев первой реализации с Radix**. Его хеши и результаты относятся к прежним исходникам. Они не являются доказательством проверки новой компонентной структуры и Base UI.

Текущая приёмка сохраняется отдельно в [verification-component-foundation.json](verification-component-foundation.json): проверки и отпечатки исходников относятся к компонентной основе. **8 ноября прошли 15 браузерных сценариев** в изолированном Chrome на синтетических данных при ширинах 1440/768/390/380 px, с неизменными исходниками во время прогона. Проверены формы, диалоги и возврат фокуса, выбор/сравнение, отдельная загрузка графика, черновик и JSON-перенос; ошибок JavaScript, console errors и внешних запросов не зафиксировано. Установленное расширение и живой Avito этим не проверены.

`npm run licenses:collect` воспроизводит сводку и исходные уведомления из установленного lock и отчёта о включённом в сборку runtime. `npm run licenses:check` сравнивает без записи; финальная проверка с `--require-bundle-report` описана в [REUSE.md](REUSE.md). [Исходные уведомления и границы аудита](THIRD-PARTY-NOTICES.md) сохранены; собственная лицензия проекта пока не выбрана. Сохранённые notices не являются юридической гарантией отсутствия претензий.

`npm run zip` создаёт установочный архив в `.output`. Сборочные файлы, node_modules и пользовательские JSON не коммитятся. Сайт базы публикует отдельный статический web-preview по `/avitolog/prototype/`.
