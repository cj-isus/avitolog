# АВИТОЛОГ — база существующих решений

**[Открыть интерактивную базу знаний →](https://cj-isus.github.io/avitolog/)** · [Как обновляется сайт](knowledge-site/README.md)

Срез на **5 ноября 2026 года**. Собраны **1 811 публичных репозиториев по метаданным** и **37 отдельных карточек кандидатов**: у 35 проверены выбранные исходники, у одного — README, ещё один обнаружен в индексе, но live-источники отвечают 404. Отдельно описаны 6 смежных проектов. Это широкая выборка; полнота всего GitHub не заявляется.

Сейчас исследуем готовые решения и возможность переиспользования. Состав MVP и стек пока не выбраны.

## Находки, с которых удобно начать сравнение

Это кандидаты на разбор, а не выбранная архитектура или подтверждение готовности к эксплуатации.

| Проект | Уже реализовано | Главное ограничение |
|---|---|---|
| [avito-personal-mcp](https://github.com/AlexButiev/avito-personal-mcp) | Поиск, карточки, чаты; двухэтапная отправка в существующий чат | MIT; нужен подходящий Chrome/CDP, открытие любого нового диалога не подтверждено |
| [ermizin/avito-mcp](https://github.com/ermizin/avito-mcp) | Браузерные действия, извлечение карточек и фото | MIT; отдельный профиль браузера, Windows и текущий сайт не проверены |
| [avito-gpu-helper](https://github.com/ForseJDM/avito-gpu-helper) | Настоящее расширение в выдаче: сравнение, значки, движок цены | MIT-текст с trademark note; предметная модель GPU, LLM нет |
| [Case211/avito-watch](https://github.com/Case211/avito-watch) | Мониторинг, история цены, медиана выдачи, optional LLM | AGPL-3.0; качество оценки и сопоставимость товаров не измерены |
| [domovoyproj/avito-parser](https://github.com/domovoyproj/avito-parser) | Панель, история, объяснимый скоринг и optional LLM | Лицензия не найдена: изучение подходов отделено от переноса кода |
| [Egor01KKK/avito-parser](https://github.com/Egor01KKK/avito-parser) | JSONL для AI-агента, мониторинг, групповой анализ цен | Лицензия не найдена; анализ заточен под телефоны |
| [elchin92/avito-mcp](https://github.com/elchin92/avito-mcp) | MCP официального API, Messenger, preview/confirmation | MIT; API-права аккаунта, не замена браузерного покупательского поиска |

Источники конкретных функций и оговорки сохранены в [карточках](research/catalog.md). Сторонние SDK официального API не являются официальными SDK самого Avito и не превращают браузерную авторизацию в API-доступ.

## Данные для дальнейшего исследования

- Широкая выборка: [JSON](research/data/github-repositories.json), [CSV для таблиц](research/data/github-repositories.csv), [журнал поиска](research/data/search-coverage.json).
- Отобранные карточки: [JSON](research/data/deep-reviews.json), [CSV](research/data/deep-reviews.csv).
- Контроль целостности: [manifest исходной выборки](research/data/snapshot-manifest.json), [проверка выборки](research/data/inventory-validation.json), [проверка итоговой базы](research/data/knowledgebase-validation.json).
- Присланный обзор: [неизменённая копия](research/inputs/user-research-2026-11-05.txt).

В широком реестре есть учебные задачи, клоны, проекты компании и одноимённые сервисы. Публичность кода не означает установленную OSS-лицензию: метаданные лицензии отсутствуют у 1 604 из 1 811 записей. Для важных кандидатов текст лицензии проверялся отдельно.

Чужой код не запускался, совместимость с текущим Avito и качество оценок не измерялись. Следующее содержательное действие — сравнить выбранные компоненты и условия их переиспользования; затем можно определить MVP.
