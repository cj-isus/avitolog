# Дополнительные интеграции Avito: клиенты API, диалоги и анализ цены

Проверено 2026-11-05. Это дополнение к основному каталогу. Выполнено чтение README, LICENSE, деревьев и выбранных исходников публичных репозиториев. Ничего не устанавливалось, не запускалось и не подключалось к аккаунту Avito. Наличие исходников или тестов не подтверждает работу с текущим сайтом. Проектирование MVP и оформление курсовой отложены по уточнению пользователя.

## Похожее расширение, но для другого сервиса и рынка

[itsma3il/Avito-Price-Estimator-Extension](https://github.com/itsma3il/Avito-Price-Estimator-Extension) — MIT, React/Vite/Tailwind, MV3-расширение оценки автомобилей для **avito.ma, Марокко**. Это не интеграция российского avito.ru. Manifest разрешает только `https://www.avito.ma/*`; DOM-extractor читает французские поля автомобиля. README ссылается на отдельную модель и говорит, что репозиторий backend API ещё будет опубликован. Можно изучить интерфейс extension → DOM features → оценка, но готовность end-to-end не доказана и правила/модель цены неприменимы к велосипедам в Москве. Push: 2025-06-13. [Manifest](https://github.com/itsma3il/Avito-Price-Estimator-Extension/blob/main/public/manifest.json), [extractor](https://github.com/itsma3il/Avito-Price-Estimator-Extension/blob/main/src/utils/scraper.js), [LICENSE](https://github.com/itsma3il/Avito-Price-Estimator-Extension/blob/main/LICENSE).

## Выводы для основной базы

1. Реальные близкие проекты есть, в том числе с LLM-анализом покупательских объявлений: утверждение «готового анализа выгодности вообще нет» было бы слишком сильным. При этом source-проверка ещё не доказывает качество цены, оценку износа и текущую работу на Avito.
2. Case211/avito-watch стоит включить в список углублённого изучения рядом с основной шестёркой: он покрывает историю цены, медиану выдачи, объяснение и релевантность. Уточнить качество сопоставимых объектов, воспроизводимость LLM-вердиктов и ограничения AGPL перед интеграцией кода.
3. Сторонние клиенты официального API полезны для легитимного API-канала при нужных правах. Они не устраняют покупательские ограничения API одним фактом наличия библиотеки.
4. Seller-side боты пригодны как источники подходов к диалогам, очередям и разделению генерации/отправки. Не смешивать это с готовым автономным торгом от покупателя.
5. В каталоге нужно различать подтверждённую OSS-лицензию, заявление лицензии только в README, модифицированный текст лицензии и public source без лицензии.
6. Даты push получены через публичный GitHub REST API и не означают дату релиза или успешный runtime-check. Primary metadata: `https://api.github.com/repos/OWNER/REPO`; дерево: `https://api.github.com/repos/OWNER/REPO/git/trees/HEAD?recursive=1`.
