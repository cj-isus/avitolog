# Как собрана база

Дата проверки: **5 ноября 2026 года**. Задача — найти существующие Avito-проекты и понять, какие части уже реализованы и доступны для переиспользования. Выбор архитектуры и состава MVP отложен до разбора каталога.

## Два уровня каталога

**Широкий реестр** содержит 1 811 уникальных публичных репозиториев из GitHub Search API. В нём сохранены описание, язык, звёзды, даты, archived, лицензия по метаданным GitHub, поисковые запросы и предварительная категория. Все записи имеют `metadata_only=true`, `runtime_tested=false`. Категория назначена эвристикой по имени и описанию; она не подтверждает функции проекта.

**Отобранный каталог** содержит 37 кандидатов с разным уровнем проверки: у 35 прочитаны описание и выбранные исходники, у одного — README, ещё один найден в индексе, но live-источники отвечают 404. Наличие и содержание лицензии проверялись отдельно; отсутствие файла тоже зафиксировано. Это адресная проверка конкретных функций. Она не является полным аудитом репозитория, доказательством качества оценки цены или работоспособности на сегодняшнем Avito. Поля `review_level`, `sources`, `runtime_verification` фиксируют уровень доказательств в [JSON](data/deep-reviews.json).

Отобранный каталог может содержать проекты, не попавшие в широкую выборку. Эти множества нельзя складывать. Сопоставление по `repo/full_name` сохранено в [проверке базы](data/knowledgebase-validation.json).

## Охват и ограничения поиска

Выполнены запросы `avito in:name,description`, `авито in:name,description` и отдельные срезы MCP, extension, AI, LLM, ChatGPT, bot, price, monitor. Полные URL, страницы, время, `total_count`, `incomplete_results`, ошибка транспорта и успешный повтор сохранены в [журнале](data/search-coverage.json).

Основной запрос сообщил о **10 120** результатах; получены первые **1 000**. Кириллический сообщил о **804**; получены первые **300**. Дополнительные срезы расширили объединённую выборку до **1 811** репозиториев после удаления дубликатов. Всего сохранены 22 успешных ответа страниц. Одна временная SSL-ошибка не потеряла страницу: повтор завершился успешно.

GitHub Search API возвращает максимум 1 000 результатов на запрос и по умолчанию сортирует их по best match. Во время последовательного сбора выдача может изменяться. Поэтому это **широкая выборка, не полный список всех проектов GitHub**. [GitHub Search API](https://docs.github.com/en/rest/search/search#about-search)

Поиск по умолчанию исключает forks; для их включения нужен `fork:true` или `fork:only`. Для дальнейшего расширения можно отдельно обходить forks, темы, языки и интервалы дат. [Синтаксис поиска репозиториев](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories)

В реестре намеренно сохранён поисковый шум: учебные задания, клоны сайта, проекты avito-tech, Kaggle, avito.ma. Удаление по одному названию рисковало бы скрыть полезные находки. В основном каталоге такие случаи помечены отдельно.

## Что означает лицензия

Публичный репозиторий не следует автоматически называть open source с разрешением включать его код в другой продукт. GitHub позволяет просматривать и форкать публичные репозитории по своим условиям, но отсутствие лицензии не даёт общего разрешения распространять производный код. [GitHub: лицензирование репозитория](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

У широкого реестра **198** записей с определённым SPDX, **1 604** без метаданных лицензии и **9** с `NOASSERTION`. Это результат автоматического определения GitHub. Важные проекты проверены отдельно по LICENSE, package metadata и README. `NOASSERTION` не всегда означает отсутствие лицензии: например, у GPU Helper найден MIT-текст с дополнительной заметкой о торговых марках.

В карточках различаются полный текст лицензии, декларация только в README/package.json, изменённый текст и отсутствие найденной лицензии. MIT/Apache/AGPL не объединяются в один режим переиспользования. Для выбора кода нужно проверить применимые условия, notices и зависимости конкретных файлов. Лицензия репозитория также не подтверждает право на чужие датасеты или доступ к сервису.

## Источники и даты

Часть ссылок закреплена за commit SHA, часть ведёт на default branch в момент проверки. Поле `source_pinning` различает закреплённые, изменяемые, смешанные и недоступные источники. Проверять конкретный адрес полезнее, чем предполагать одинаковый режим у всей карточки. `pushed_at` — время push в репозиторий; это не дата релиза и не обязательно дата последнего коммита default branch. Дата committer приводится отдельно, когда проверена.

Исследование пользователя сохранено [как исходный материал](inputs/user-research-2026-11-05.txt), SHA256 — в [сверке](reconciliation.md). Его внутренние ссылки вида `turn...` непереносимы и не являются доступными здесь первоисточниками. Названия проектов использованы как поисковые кандидаты; существенные утверждения проверялись заново. Коммерческие цены и тарифы Avito из этого текста не перенесены в подтверждённые факты.

## Границы проверки

Чужой код не устанавливался и не запускался. К аккаунту Avito исследование не подключалось, сообщений продавцам не отправляло, настройки сети не меняло. `archived=false`, свежий commit, наличие tests или скриншота автора не доказывают успешную работу у нас. Поле runtime у всех карточек — `not_run`.

Оценки «можно взять», «интересный референс» и «близко к нужному сценарию» — наша оценка по прочитанным файлам. Она не является измерением качества или готовности к эксплуатации.
